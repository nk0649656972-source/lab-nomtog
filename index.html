การบำรุงรักษาและเพิ่มประสิทธิภาพ Windows 11 & อุปกรณ์พกพา

หัวข้อที่ 4.1

การจัดการพลังงาน (Power Plan) บน Windows 11

การเลือกโหมดพลังงาน หรือ Power Mode ช่วยให้เราเลือกระดับความเร็วของเครื่องให้เหมาะกับการใช้งานจริงได้อย่างสมดุล ซึ่งช่วยยืดอายุแบตเตอรี่ และป้องกันไม่ให้เครื่องร้อนเกินไป

เน้นประหยัดแบต

Best Power Efficiency

เหมาะสำหรับ: การพิมพ์งานเอกสาร ท่องเว็บอ่านบทความ หรือใช้นอกสถานที่ เครื่องจะเย็น เงียบ และใช้งานได้ยาวนานที่สุด

แบตเตอรี่อยู่นานสูงสุด ปราศจากเสียงพัดลมนกกดดัน
แนะนำใช้งานทั่วไป

Balanced Mode

ระบบจะปรับความเร็วสมองกล (CPU) ตามความหนักของงานโดยอัตโนมัติ ให้ความลื่นไหลกำลังดีและประหยัดพลังงานพร้อมกัน

เหมาะสำหรับการใช้งานในชีวิตประจำวันมากที่สุด
ความเร็วสูงสุด

Best Performance

เหมาะสำหรับ: งานตัดต่อวิดีโอ การเรนเดอร์กราฟิก หรือเล่นเกมที่ต้องการความเร็วการประมวลผลขั้นสุด

ใช้พลังงานสูงกว่า และอาจมีความร้อนเพิ่มขึ้น

หัวข้อที่ 4.2 (เพิ่มเติม)

การดูแลรักษาแบตเตอรี่และยืดอายุอุปกรณ์พกพา (Smartphones & Tablets)

อุปกรณ์พกพาใช้แบตเตอรี่ประเภท Lithium-ion / Lithium-polymer ซึ่งการดูแลอย่างถูกวิธีจะช่วยให้แบตเตอรี่ไม่เสื่อมสภาพเร็วและปลอดภัยจากการพองตัว

กฎการชาร์จ 20% - 80%

อย่าปล่อยให้แบตเตอรี่หมดจนเหลือน้อยกว่า 20% และไม่จำเป็นต้องชาร์จแช่ทิ้งไว้ข้ามคืนเพื่อลดแรงดันสะสมในเซลล์แบต

หลีกเลี่ยงความร้อนสูง

ศัตรูอันดับหนึ่งของแบตเตอรี่คือความร้อน ไม่ควรเล่นเกมขณะชาร์จ หรือวางมือถือไว้คอนโซลรถที่ตากแดดจัด

การล้างไฟล์ขยะหน่วยความจำ

ลบไฟล์แคช (Cache) ในแอปโซเชียลมีเดียเป็นประจำ ช่วยคืนพื้นที่ความจุ และทำให้สมาร์ทโฟนทำงานลื่นไหลไม่ติดขัด

ความปลอดภัยและการสำรองข้อมูล (Security)

หัวข้อที่ 5.1

การตั้งค่าความปลอดภัยในการลงชื่อเข้าใช้: Windows Hello

Windows Hello คือระบบยืนยันตัวตนที่เป็นมิตร สะดวก และปลอดภัยสูง ช่วยให้เข้าใช้งานเครื่องได้โดยไม่ต้องพิมพ์รหัสผ่านยาวๆ ทุกครั้ง

1. สแกนใบหน้า (Facial)

ใช้กล้องอินฟราเรด (IR Camera) ตรวจจับเค้าโครงใบหน้าแบบ 3 มิติ ยิ้มให้กล้องก็พร้อมเข้าใช้งานทันที

ปลอดภัย ไม่โดนหลอกด้วยภาพถ่าย

2. สแกนลายนิ้วมือ (Fingerprint)

เพียงแตะนิ้วมือลงบนจุดสแกน สะดวก รวดเร็ว เหมือนการปลดล็อกโทรศัพท์มือถือที่เราคุ้นเคย

แตะปุ๊บ ปลดล็อกปั๊บ

3. รหัส PIN (Windows Hello PIN)

รหัสตัวเลขสั้นๆ ที่ผูกแน่นกับฮาร์ดแวร์ชิป TPM ในเครื่องนั้นๆ แม้คนอื่นรู้รหัสไป ก็นำไปกดบนเครื่องอื่นไม่ได้

ล็อคเฉพาะเครื่องปลอดภัยสูง

อุ่นใจด้วยความปลอดภัยระดับฮาร์ดแวร์ TPM 2.0

ข้อมูลลายนิ้วมือ ใบหน้า และรหัส PIN จะถูกจัดเก็บและเข้ารหัสอยู่ภายในชิป TPM 2.0 บนเมนบอร์ดคอมพิวเตอร์อย่างมิดชิด โดยไม่มีการส่งข้อมูลออกไปภายนอกอินเทอร์เน็ต

การวิเคราะห์และแก้ไขปัญหา (Troubleshooting)

หัวข้อที่ 6.1

การเข้าสู่ Safe Mode ใน Windows 11

Safe Mode (เซฟโหมด) เปรียบเหมือน "โหมดความปลอดภัย" ที่ระบบจะเปิดทำงานเฉพาะโปรแกรมที่จำเป็นเท่านั้น เหมาะสำหรับใช้แก้ไขเวลาเครื่องค้าง ติดไวรัส หรือลงโปรแกรมผิดพลาด

วิธีที่ 1

ผ่าน Windows Settings

  1. ไปที่ Settings > System > Recovery
  2. ที่หัวข้อ Advanced startup กด Restart now
  3. เลือก Troubleshoot > Advanced options > Startup Settings
  4. กด Restart แล้วเลือกกดเลข 4
วิธีที่ 2

ผ่าน Shift + Restart

  1. เปิดเมนู Start แล้วคลิกปุ่ม Power
  2. กดปุ่ม Shift ค้างไว้ แล้วกด Restart
  3. เครื่องจะพาเข้าสู่หน้าจอสีฟ้า Choose an option
  4. เลือก Startup Settings เพื่อเข้า Safe Mode
วิธีที่ 3

เมื่อเครื่องบูตไม่ติด

  1. กดปุ่ม Power เปิดเครื่อง พอขึ้นโลโก้ให้กด Power ค้างจนดับ
  2. ทำซ้ำ 2-3 ครั้ง ระบบจะเปิด Automatic Repair ให้เอง
  3. เลือก Advanced Options เพื่อเข้า Safe Mode
หัวข้อที่ 6.2

การซ่อมแซมไฟล์ระบบด้วยคำสั่ง sfc /scannow

คำสั่ง sfc /scannow ทำหน้าที่เหมือนหมอตรวจสุขภาพคอมพิวเตอร์ จะช่วยค้นหาไฟล์ระบบที่เสียหายและทำการซ่อมแซมซ่อมให้อัตโนมัติ

คำสั่งสแกนซ่อมไฟล์ (Main SFC)
sfc /scannow

ตรวจและซ่อมไฟล์ระบบที่เสียหายอัตโนมัติ

คำสั่งซ่อมคลังระบบ (DISM)
DISM /Online /Cleanup-Image /RestoreHealth

ดึงไฟล์ต้นฉบับมาซ่อมแซมคลังระบบ

หัวข้อที่ 6.3

การวิเคราะห์ปัญหาหน้าจอฟ้า (Blue Screen of Death - BSOD)

หน้าจอฟ้า BSOD คือแจ้งเตือนฉุกเฉินเมื่อระบบทำงานผิดปกติ เพียงเราสังเกตรหัส Stop Code ก็จะรู้วิธีแก้ไขได้ทันที

เลือกคลิกรหัสข้อผิดพลาดเพื่อดูคำแนะนำการแก้

DRIVER_IRQL_NOT_LESS_OR_EQUAL ปัญหาจากไดรเวอร์อุปกรณ์

เกิดจากโปรแกรมคุมอุปกรณ์ (เช่น การ์ดจอ การ์ดเสียง Wi-Fi) ล้าสมัย หรือขัดแย้งกัน

แนวทางแก้ไข:
  • อัปเดตไดรเวอร์อุปกรณ์ผ่าน Device Manager
  • ถอนการติดตั้งโปรแกรมหรือไดรเวอร์ที่เพิ่งลงล่าสุด
  • สแกนซ่อมไฟล์ระบบด้วย sfc /scannow
